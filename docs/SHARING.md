# 分享主机

[English](SHARING.en.md) · [首次使用](GETTING_STARTED.md)

## 分享给已注册用户或团队

1. 登录同一实例，在账户设置打开组织，创建或加入组织。默认只有实例允许的管理员可以创建组织。
2. 添加成员/团队或发出组织加入链接。接收方仍须通过该实例的账户注册或账户邀请流程；组织邀请不绕过账户注册策略。
3. 主机菜单 → **分享…** → 成员/团队。优先为所选主机建立独立共享 Vault，逐项核对复制的密钥、分组和跳板依赖；分享整个 Vault 是另一个显式选项。
4. 设置期望角色，核对接收设备指纹，再确认交付加密密钥。组织管理员不能仅靠添加访问授权就取得 Vault 密钥；“等待密钥”不等于已取得加密成员资格。
5. 已接受成员的角色变化由持有者确认 Editor/Viewer 操作。移除成员会立即限制服务端访问，但持有者仍须轮换 Vault 密钥；对方已经看过的密码、密钥等凭据应另行更换。

## 临时浏览器链接

运维需先启用 SQLite 云端能力、guacd、完整 HTTPS 来源地址、网关密钥和严格的目标 CIDR/端口规则，见[云端分享部署说明](CLOUD-SHARING.md)。

1. 先确认 SSH 主机公钥或 RDP 证书指纹。
2. 在 **分享…** 选择临时访问，设置开始/到期时间、自定义地址、打开次数、连接与并发上限，以及只读/剪贴板策略。
3. 一次性复制完整链接。密文不会再次还原为原链接，丢失时轮换；持有链接者可在策略允许范围内使用。
4. 访客用浏览器打开，点击 **继续** 兑换，再点击 **连接** 打开会话；不会自动兑换或连接。刷新只恢复当前链接对应的会话。
5. 在活动列表查看或终止会话，按需暂停、撤销或轮换链接。

网关可解密登录胶囊并观察会话，临时访问不是零知识模式。分享 API 不把登录凭据直接交给访客，但目标账户权限仍决定访客能做什么。该访客流程不提供文件/磁盘/打印/录制通道；VNC 需显式启用，尚未完成真实连接验收。

打开次数在兑换时计数；连接次数在网关准入后计数。容量/并发拒绝不消耗该次连接额度，准入后的目标或登录失败仍可能计数。时间窗口使用 UTC；尚未实现周期重复日程。

## 没有分享入口

核对服务端能力、SQLite 模式、账户/Vault 角色和目标信任状态。分享时切换账户、实例或 Vault 会取消过期操作；若旧服务端已完成某一步，错误会说明已提交，不会假称回滚，也不会把旧密钥装入新会话。
