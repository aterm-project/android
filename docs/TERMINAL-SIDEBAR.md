# SSH 右侧工具栏

本地 Profile 与云端 Vault 的 SSH 标签均提供“搜索…”、“快捷指令”和“输入历史”入口。搜索快捷键继续使用设置中的绑定。宽终端将工具栏停靠到右侧；窄窗口或较小分屏将其覆盖在右侧，关闭后恢复完整终端区域，不重建终端会话。

- **搜索**：实时搜索当前终端保留的输出，显示匹配数并高亮，支持上一个/下一个。按 Enter、切换侧栏分类或关闭时记录搜索词。每个标签最多保留 20 个去重搜索词，可点击复用、逐条移除或清空；仅存在内存中，关闭标签或锁定后释放。
- **快捷指令**：读取当前 Profile / Vault 的 Snippets。支持名称/内容筛选、添加、编辑、删除。此入口展示没有参数的单行 Bash 指令，保存时沿用加密 Snippet 存储；多行脚本和带凭据参数的片段仍通过片段页面管理。点击只填入终端当前光标处，由用户按 Enter 执行。控制字符和换行不能通过此入口输入。
- **输入历史**：按当前主机显示已完成的 Bash 命令，可筛选、填入、清空本机记录。首次使用打开“记录设置”，启用并复制设置命令，再粘贴到当前交互式 Bash。不会从键盘流采集密码提示输入；命令行本身包含的敏感内容仍可能被记录。远端上报的命令只是数据，不会自动执行。

云端工作区沿用已有最多 500 条的设备端加密历史和可选 Vault 同步；关闭同步或清空本机历史不会删除已经同步的记录。本地 Profile 的历史加密保存为独立偏好，每个主机最多 500 条且合计不超过 48 KiB，积压写入会合并并受同样限制；重新打开 SSH 后恢复。同一 Profile 的相同主机标签共享新增与清空通知。

本地历史仅留在本地 Profile，迁移到云端时不会隐式上传为共享偏好，原始加密记录保留在源 Profile。搜索词历史不写入磁盘。上述记录与终端滚动缓冲分别管理，侧栏不改变原有终端保留行数。

停止 Bash 采集后，在远端运行 `atermius_off` 或关闭 Shell 可移除该会话钩子。不修改远端启动文件。
